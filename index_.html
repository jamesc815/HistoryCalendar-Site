History Calendar

A simple way to keep a running log of what happens on any given day — one entry at a time, kept entirely in your own hands.

What it does

History Calendar lets someone pick any date and record the events that happened on it — a meeting, a symptom, a milestone, a small note worth remembering. Each day builds its own short list of entries.

Core features

  • 1
    Record events by day
    Choose a date for the event and add a short note about what happened.

    1
    Add events
    Tap the “+” button at the top of the app page. Selected the day that the event occurred (the date defaults to the current day. Add a short note about what happened and save to event.

    2
    Remove events
    Any entry can be deleted from its day's list if it was added by mistake or is no longer needed.

    3
    Export everything
    Every event ever logged can be bundled into a single file, so the whole history can be saved as a backup or moved elsewhere.

    4
    Import a backup
    A previously exported file can be loaded back in, merging its events with whatever is already recorded, so no history is lost.

How someone would use it

  1. Open the app and land on today's date, or pick another day from the calendar.
  2. Add an event with a short title, and optionally a time and a few notes.
  3. Come back anytime to review, edit by removing and re-adding, or delete entries that no longer belong.
  4. Export the full history whenever a backup is wanted, or import one to restore or transfer events.

What gets stored

Each event has two pieces of information: the date it belongs to and the event text. Exported files package all of this into one plain, portable file so a person's history isn't locked into any one device.

A typical export looks like a list of dates, each holding the events recorded for it — for example, one day might hold an entry titled Dentist appointment at 9:30, and another might hold a few untimed notes with no time attached at all.
